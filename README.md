# LizeUI Forever
LizeUI imports profiles and fixes the use of custom icons in WOW Forever (Buff / Debuff)

## Ruta de navegacion (RXPGuides)
Dibuja en gris, en el minimapa y en el mapa del mundo, la ruta que marca RXPGuides: objetivo actual, waypoints restantes del paso y los pasos siguientes (mas tenues). Opciones en Ajustes > LizeUI > Navegacion. Atajo: `/lui ruta`.
